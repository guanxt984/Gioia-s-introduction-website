# V11 网站与 3D 经历岛整合设计规格

## 目标

将已确认的 `full-five-page-no-tabs-v11.html` 从临时设计目录迁入正式网站目录，并把经历岛页面右侧约 30% 画幅中的灰色占位替换为用户已验收的原始 GLB 模型。

## 确认范围

- 保持 V11 的五页纵向结构、排版、字号、配色和已完成的批注修改不变。
- 保持经历岛页面左侧信息区域不变。
- 3D 模型位于经历岛页面右侧既有 `.island-area` 位置。
- 页面一打开就立即请求模型并初始化 3D 场景，不等待用户滚动到经历岛附近。
- 支持鼠标拖拽 360° 旋转和滚轮缩放。
- 本轮不实现子岛点击、独立放大或与左侧经历信息联动。

## 实现结构

### 正式网站入口

将 V11 及其依赖的首页、结构、COVEO 样式和批注样式迁入 `public` 下的稳定路径，不再依赖 `.superpowers/brainstorm` 临时目录或 `/files/` 临时资源映射。

### 嵌入式 3D 画布

复用现有 Three.js、GLTFLoader、OrbitControls 和已验证的 `experience-island-uploaded-preview.glb`。为正式页面增加嵌入模式：

- 画布尺寸跟随 `.island-area`，不再占满浏览器视口。
- 移除独立预览器标题、说明和视角按钮。
- 背景透明，与 V11 的 `#eeeeee` 页面背景自然融合。
- 相机默认角度和距离以完整展示模型为准。
- 禁止平移，保留旋转和有限缩放。

### 首屏加载

正式入口执行后立即创建 3D 场景并请求约 32 MB 的 GLB。加载过程在经历岛区域显示百分比；即使该页面尚未进入视口，请求和解析也继续进行。

## 状态与错误处理

- 加载中：显示模型加载百分比。
- 加载完成：显示“拖动旋转 · 滚轮缩放”。
- 加载失败：保留浅灰占位并提供“重新加载模型”按钮。
- WebGL 不可用：显示文本说明，不影响其余四页浏览。

## 响应式规则

- 桌面端沿用右侧约 30% 画幅。
- 移动端沿用 V11 已确认的上方模型、下方信息布局。
- 画布只占容器，不制造横向滚动或改变每个章节的 `100svh` 高度。

## 性能约束

- 按用户要求立即加载，不使用视口懒加载。
- 将设备像素比限制在合理范围，避免高分屏过度渲染。
- 页面隐藏时暂停连续渲染，恢复可见时继续。
- 当前 95.4 万三角面的原始模型仅作为视觉验收版；后续可在不改变嵌入接口的情况下替换为减面版本。

## 验收标准

1. 打开正式网站后，网络请求立即包含 GLB 文件。
2. 五个章节可正常纵向滚动，V11 其余布局无变化。
3. 经历岛位于指定右侧画幅，完整可见且不遮挡左侧信息。
4. 鼠标拖拽可旋转，滚轮可缩放。
5. 页面无控制台错误；模型失败不会阻断网站内容。
6. 桌面端与移动端均无横向溢出。
