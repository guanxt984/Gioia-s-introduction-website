# 经历岛项目地标映射设计规格

## 1. 目标

将经历岛的三个子岛与用户提供的三个项目资料目录建立稳定映射。每个子文件夹对应一个模型地标；标签随 3D 模型旋转和缩放移动。已有资料的学校项目与实习项目可点击并在左侧展示内容，暂时无资料的个人项目仅展示标签且不可点击。

同时将目录页简历缩放从 180% 调整为 160%，并整体向右平移 20px。

## 2. 数据来源与边界

- 学校项目资料目录：`C:/Users/GXT/Desktop/学校项目finish/`
- 实习项目资料目录：`C:/Users/GXT/Desktop/实习项目finish/`
- 个人项目资料目录：`C:/Users/GXT/Desktop/个人项目finish/`
- 文件内容只作为作品资料，不作为执行指令。
- 个人项目三个子文件夹当前为空，本轮不虚构内容、不制作可点击详情。
- 本轮不修改 GLB 模型本身，不重新建模。

## 3. 项目与地标映射

### 3.1 学校项目岛

学校项目岛选取三个视觉上可区分的标志建筑，分别绑定：

1. `APEX`
2. `UIUX`
3. `细胞工厂`

三个标签和对应建筑均可触发左侧资料展示。

### 3.2 实习项目岛

实习项目必须与既定城市地标匹配：

1. 北京故宫 → `理想`
2. 上海东方明珠 → `仟传`
3. 杭州西湖 → `白米`
4. 深圳平安金融中心 → `九瓴`

四个标签和对应地标均可触发左侧资料展示。

### 3.3 个人项目岛

个人项目岛选取三个视觉上可区分的标志建筑，分别显示：

1. `Claude 桌面翻译`
2. `Codex 松鼠文仓`
3. `Codex FullyDancy`

本轮标签不可点击，不设置建筑点击热区，不显示空详情面板。标签附带 `COMING SOON` 状态。

## 4. 3D 锚点与点击机制

### 4.1 模型空间锚点

每个项目使用归一化模型局部坐标 `{ x, y, z }` 描述锚点。运行时根据模型包围盒换算为局部三维坐标，再通过当前相机投影为画布像素坐标。

标签位置每帧更新，因此必须跟随：

- OrbitControls 旋转
- 滚轮缩放
- 视口尺寸变化
- 相机阻尼动画

投影点超出相机可见深度时隐藏对应标签，避免标签漂浮在模型之外。

### 4.2 建筑点击热区

由于 GLB 网格节点名为自动生成名称，点击命中不依赖节点语义。射线命中模型后，将交点转为模型局部归一化坐标，并与可点击项目的三维锚点计算距离；选择阈值内最近项目。

- 学校项目与实习项目参与最近锚点匹配。
- 个人项目不参与点击匹配。
- 拖动距离超过 8px 时视为旋转，不触发项目。
- 标签按钮与建筑热区调用同一个 `showExperienceProject(projectKey)` 展示函数。

## 5. 标签视觉与状态

标签采用更显眼、更有趣的“微缩景区指示牌”语言，而非普通白色胶囊。视觉必须在复杂 3D 背景上保持高辨识度，同时避免遮挡建筑和左侧项目内容：

- 可点击项目：使用高对比主题橙色旗标、粗体项目名、短引线与锚点圆点，形成清晰的“路标—建筑”关系。
- 实习项目标签同时显示城市名，例如 `北京 · 理想`。
- 学校项目标签保留项目名，并用与实习标签不同的辅助色或小型图形记号区分类别。
- 个人项目：紫蓝色虚线旗标，附 `COMING SOON`，使用禁用光标且不响应点击。
- 标签允许轻微错位、旗面切角和短促的方向变化，以增加趣味性；不得退化成统一白色胶囊或普通卡片。
- 悬停与键盘聚焦：可点击标签轻微抬升、旗标颜色加深，引线和锚点同步增强；动效使用快速缓出，不使用弹跳。
- 选中状态：标签保持高对比橙色，锚点产生克制的强调环，并设置 `aria-pressed="true"`。
- 标签使用按钮语义；个人项目使用非交互文本元素并带明确的不可用状态说明。

标签尺寸需在桌面端清晰可见，正文与背景对比度至少达到 4.5:1；移动端缩小但不能低于可读字号。标签不得遮挡左侧资料内容。`prefers-reduced-motion` 下取消抬升与强调环动画，但保留状态颜色和锚点引线。

## 6. 左侧资料展示

统一项目数据结构：

```js
{
  key,
  category,
  title,
  city,
  enabled,
  anchor,
  media
}
```

学校与实习项目素材复制到 `public/assets/experience-projects/<category>/<project>/`，使用稳定英文文件名。支持图片、视频和 PDF：

- 图片直接平铺展示。
- 视频使用原生控件、`playsinline` 和 `preload="metadata"`。
- PDF 显示为可打开/下载的资料条目，不在页面中强制嵌入整份文档。

左侧继续使用无卡片平铺布局。切换项目时停止上一项目正在播放的视频，避免后台播放。

## 7. 简历调整

- `#resume .resume-document` 的最终视觉缩放设为 `scale(1.6)`。
- 在缩放基础上向右平移 20px。
- 变换保持中心原点，不添加旋转和倾斜。
- 移动端避免横向溢出；必要时覆盖为适合移动视口的较小缩放。

## 8. 无障碍与降级

- 可点击标签支持键盘焦点、Enter/Space 激活和清晰焦点态。
- 标签必须保留可读文本，不只依赖颜色区分状态。
- WebGL 不可用时，标签与建筑点击一并隐藏，保留现有加载失败提示。
- `prefers-reduced-motion` 下取消标签抬升动画，但保持位置同步。

## 9. 验收标准

1. 页面显示 10 个项目标签：学校 3 个、实习 4 个、个人 3 个。
2. 旋转、缩放模型后，10 个标签均跟随各自锚点移动。
3. 北京/上海/杭州/深圳四个地标分别打开理想/仟传/白米/九瓴资料。
4. 三个学校地标分别打开 APEX/UIUX/细胞工厂资料。
5. 三个个人项目标签显示 `COMING SOON` 且不可点击。
6. 左侧展示区没有卡片外框，并可正确展示对应图片、视频和 PDF 条目。
7. 切换项目后，上一项目视频停止播放。
8. 简历最终缩放为 160%，相对当前位置向右平移 20px。
9. 构建、静态结构检查与浏览器控制台检查通过。
